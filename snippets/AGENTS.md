# Global AGENTS.md

## 役割
この Codex 環境には、プロジェクトごとに分離された長期記憶がある。

## 長期記憶の前提
- 各プロジェクトの記憶本体は `~/.codex/projects/<project-id>/memory.db` に保存される。
- repo root の `MEMORY.md` は自動生成されたフロントページであり、全文ではない。
- `MEMORY.md` は参考情報だが、現在のコードと現在のユーザー指示を優先する。
- `MEMORY.md` は手で編集しない。

## いつ記憶を参照するか
次の状況では、回答や実装に入る前に記憶を参照する。

- 前回の議論を前提にしている
- 以前の設計判断、却下理由、ハマりどころが関係する
- 記事構成、命名、アーキテクチャ、移行方針、戦略判断を行う
- 「以前」「前回」「続き」「引き継ぎ」「却下した理由」「なんでやめた」など、継続性シグナルがある

## どうやって記憶を参照するか
必要なら次のコマンドを実行する。

```bash
"$HOME/.codex/memory-runtime/.venv/bin/python" "$HOME/.codex/bin/codex_memory.py" search --cwd "$PWD" --query "<自然言語クエリ>"
```
